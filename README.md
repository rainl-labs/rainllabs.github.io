# Rain Labs website

A static, responsive site designed for GitHub Pages. It uses only `index.html`, `styles.css`, `script.js`, and a local SVG mark—no build step is required.

## Customize before publishing

1. In `index.html`, replace `your-email@example.com` with the studio email address.
2. Replace every `href="#"` for Tenebrix trailer/store and social destinations with real URLs.
3. Replace the decorative Tenebrix art panel with gameplay images or a game logo when available. An example comment is in the HTML beside that panel.
4. Update the game status, genre, and project copy only when those details are ready to share.

## Publish on GitHub Pages

1. Create a GitHub repository and upload the contents of this folder (not the folder itself as an extra level).
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, then choose `/(root)` and save.
4. GitHub will display the live site URL after deployment.

The site needs an internet connection to load the optional Google Fonts; it otherwise works as a normal static website.
